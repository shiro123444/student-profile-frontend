# WebAgent 能力矩阵与 P7 启动清单（2026-02-22）

## 1) 评估口径

### 智能等级定义（L0-L5）
- **L0**：无 Agent 接入
- **L1**：单轮问答（无工具/无编排）
- **L2**：可调用工具，但无过程可视化
- **L3**：可编排多步任务，具备部分观测与回执
- **L4**：多 Agent / DAG 编排 + 审批/审计 + 回放/复盘
- **L5**：跨域自治链路（可控交易语义 + 全局记忆一致性 + 稳定 SLA）

## 3) 后端智能通路矩阵

| 通路 | 状态 | 当前说明 | 关键缺口 |
|---|---|---|---|
| 双引擎路由（Claude + OpenAI-compatible） | ✅ | runtime 支持 engine/model/mode，快慢链路可切换 | 尚未沉淀“自动路由策略画像” |
| DAG 编排（planner/gather/act/synthesize） | ✅ | 分层并发、retry、timeout、budget、critique/replan | 缺跨域任务模板库 |
| 跨链路 run scratchpad 共享 | ✅ | OpenAI 升级 Claude 可携带 run 记忆 | 仍是 run 级，非长期共享记忆池 |
| Coding 审批（per-call） | ✅ | 高风险操作触发 `approval_request/result` | 审批策略尚未按业务域细分 |
| Coding 沙箱与策略 | ✅ | 路径白名单、命令白名单、默认禁网、并发槽 | 仍为进程级，未上容器级隔离 |
| 审计落库（Postgres） | ✅ | `agent_action_audit` 覆盖高风险动作与批次回执 | 缺统一审计查询页面 |
| 图谱回执/批次时间线 | ✅ | PG 优先 + Redis 回退，支持游标分页 | 缺 step 区间回放/失败步骤回放 |
| 网关遥测（metrics + history） | ✅ | 429/503/latency/circuit + 历史窗口查询 | 缺基于指标的自适应调度 |
| 外部 MCP 接入 | ⏳ | 适配链路已具备，默认开关关闭 | 缺生产级治理与可视化管理 |
| 跨域事务批次协议 | ❌ | 仅图谱批次具备补偿语义 | 笔记/PDF/数据链路尚无统一事务协议 |

## 4) 当前系统所处阶段（结论）

### 当前定位
- **整体处于 L3.5 ~ L4.0 之间**：已具备“可编排、可审批、可审计、可复盘”的 WebAgent 工程底座。
- **尚未达到 L5**：跨域自治任务链路（笔记 + 图谱 + PDF + RAG + 实验）还没有统一事务协议和统一执行入口。

### 你现在可以对外强调的能力
1. 双链路快慢模型协同（OpenAI-compatible + Claude）。
2. DAG 多 worker 编排（含 critique/replan）。
3. 高风险工具审批与全链路审计。
4. 图谱命令批次执行、回滚与回放。

### 当前仍应避免过度承诺
1. “全站一键自治完成复杂任务”。
2. “长期统一记忆池跨会话一致推理”。
3. “所有业务域都具备事务补偿语义”。

## 5) P7 分波次实施（从现在开始）

### P7-1（用户可见闭环，3~5 天）
- 在 `AIAdvisor` 增加“跨板块任务模板”入口：笔记整理、图谱分析、文档沉淀、实验复盘。
- 输出统一任务回执卡（步骤、工具、审批、结果、失败原因）。
- 将 `Notes/Documents/Experiments` 的 `AgentClusterBoard` 与任务回执事件统一协议化。

**验收**
- 用户能在一个入口看到跨板块任务全过程。
- 至少 3 条任务模板可完整跑通并生成回执。

### P7-2（图谱写能力 + 审批补偿，5~7 天）
- 新增图谱写工具：实体/关系增删改（最小集）。
- 所有写操作纳入审批 + 审计。
- 批次协议扩展 `transaction_id` 与 `compensation`（最小可用版）。

**验收**
- 图谱写任务具备“通过/拒绝/失败补偿”完整链路。
- 每次写操作在审计表可检索。

### P7-3（跨域事务链，7~10 天）
- 定义跨域批次协议（notes/pdf/graph/rag/tool）统一 step contract。
- 支持“部分成功 + 补偿回滚 + 最终汇总”。
- 输出 SDK 级接口草案：`ExecutionPlan` / `ActionReceipt` / `CompensationStep`。

**验收**
- 一条“文档检索 -> 笔记沉淀 -> 图谱更新 -> 导出”任务可事务化执行。
- 失败时可回滚并给出结构化失败报告。
