## 项目简介（300字）

当前，超过 75% 的大学生对职业规划感到迷茫，高校就业指导中心人力有限（平均 1 名老师服务 500+ 学生），而市面上的 AI 教育产品多为简单问答，缺乏深度规划能力。PathMind AI 针对这一痛点，构建了基于多智能体协同的智能职业规划与学习路径系统。

本项目的核心创新在于：首次将 Claude Agent SDK 与 MCP（Model Context Protocol）协议引入教育场景，构建了 11 个专业 AI 智能体协同工作的系统架构。不同于传统 AI 产品的"单一模型问答"模式，我们实现了职业顾问、学习教练、笔记助手等多角色智能体的任务委托与编排，通过 24 个标准化工具实现职业规划、学习指导、知识管理等复杂任务的自动化处理。

技术上，系统采用三层架构（React 前端 + Go 高性能代理 + Python AI 服务），支持实时流式交互，用户体验媲美 ChatGPT；集成多模态检索能力，可处理文档、笔记、代码等多源知识；引入工具沙箱与审批机制，保障 AI 操作的安全性与可控性。相比市面产品，我们的技术壁垒在于完整的智能体运行时与工具编排系统，而非简单的语言模型调用。

社会价值方面，本项目通过 AI 替代传统 1 对 1 咨询师，将优质职业规划服务的边际成本降至接近零，促进教育公平；助力大学生精准就业，减少职业试错成本。商业模式采用 B2B2C（高校采购）+ SaaS 订阅，预计前 3 年覆盖 100 所高校，服务 50 万学生，年收入可达 2,500-5,000 万元。
