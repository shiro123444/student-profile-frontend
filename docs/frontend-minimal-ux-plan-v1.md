# Frontend Minimal UX Plan v1

## 目标

- 让用户一进页面就看到「主要任务输入 + 结果」，而不是系统日志。
- 保留多 Agent 编排能力，但默认折叠到“系统细节”层。
- 统一液态玻璃风格，减少视觉噪音，放大标题与关键信息层级。

## 设计原则

- 主任务优先：首屏 70% 以上区域用于输入与结果。
- 细节后置：编排/审批/回执/会话放到次级可展开区域。
- 文案简短：标题一句话，副标题一句话，按钮用动作动词。
- 信息分层：主信息 `text-3xl~5xl`，系统状态 `text-[11px]`。

## 页面结构（统一）

1. Hero 区（大标题 + 简介 + 主操作）
2. 主交互区（聊天/编辑/检索）
3. 结果区（回答、检索命中、任务结果）
4. 系统细节区（默认收起）

## 已实施（本轮）

- AIAdvisor：
  - 增加 Claude 风格主标题 Hero 区；
  - 运行参数和日志面板移入“系统细节”；
  - 集群看板/事件流/会话默认收起。
  - Hero 右侧媒体位支持 URL 注入（GIF/图片/WebM/MP4）。
  - 系统细节统一为单一右侧抽屉来源（总览/事件/会话 Tab 互斥）。
- Notes/Documents/Experiments：
  - Agent 集群与回执面板默认收起，按需展开。
  - Notes 顶栏改为“书写优先”，系统能力缩到次级按钮，避免喧宾夺主。
  - Notes 新增专注写作模式（快捷键 `Ctrl/Cmd + Shift + F`）。
  - Notes 系统面板新增 Obsidian 插件目录入口（轻量兼容）。

## 下一步（P7-UI）

- P7-UI-2：统一按钮层级（Primary/Secondary/Text），减少重复样式。
- P7-UI-4：移动端简化，仅保留主输入与核心结果，系统细节改到底部 Sheet。
- P7-UI-5：将“系统细节”整体升级为可配置右侧栏（Tabs + 可持久化布局）。
- P7-UI-6：笔记页引入专注写作模式（隐藏除编辑器外次要元素）。
